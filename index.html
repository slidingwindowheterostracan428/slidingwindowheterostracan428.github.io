🔧 gh-stack – Stacked PRs Made Simple

⬇️ Download gh-stack for Windows

gh-stack is a GitHub CLI extension that helps you manage stacked pull requests without headaches. If you work with multiple code changes that depend on each other, this tool keeps everything organized. You do not need to be a developer to use it. Just download, install, and run.

🚀 Getting Started

Follow these steps to get gh-stack running on your Windows computer. The whole process takes less than 5 minutes.

Step 1: Install GitHub CLI
gh-stack works as an extension to the official GitHub CLI (gh). If you do not have it yet:
  • Go to cli.github.com
  • Download the Windows installer (MSI or EXE)
  • Run the installer and follow the on-screen steps
After installation, open Command Prompt or PowerShell and type gh --version. You should see a version number.
